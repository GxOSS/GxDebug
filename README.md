# GxDebug
ESP32 based tool for debugging the Xbox 360 boot process

## features
- POST code reading (Somewhat functional, needs refining)
- SMC UART (no)
- Kernel UART (Works? Do not connect kernel tx pin or it will break and don't ask me why it breaks)
